# 切换到公开 PyPI（放弃私有源）

## 背景

之前 `zjcode` fork 走 `http://8.152.204.58:48080/simple/` 私有 `pypiserver`，`/update` 命令通过 `--index-url` 引导 `uv tool install -U` 从私有源升级。本轮决定放弃私有源，改为上传公开 PyPI（`https://pypi.org/`），并把版本从 `0.0.1` 重新开始。同时优先与上游 `deepagents-code` 保持同步，只保留 zjcode 品牌化必需的差异。

- pypi.org 上 `zjcode` 名字空的（JSON API 返回 404），可用。
- 判断包名可用性的标准接口只有 JSON API 和 Simple Index，`/project/<name>/` HTML 页会被 Cloudflare 反爬拦成 200，不能作为依据。

## 备份

工作区在切换前已经全部提交，HEAD 为 `b9afc1845`。

- 备份分支：`backup/learn-private-source-20260719-032811`

- 分发名（PyPI project name）：`zjcode`
- Python 包目录：仍保留 `deepagents_code/`（降低上游合并冲突）

### 新增 `libs/code/run-publish.sh`

极简发布脚本，走公开 PyPI：

```bash
#!/bin/bash
set -euo pipefail
cd "$(dirname "$0")"

rm -rf dist/
uv build
uv publish "$@"
```

依赖：`UV_PUBLISH_TOKEN` 或 `~/.pypirc` 提供凭据。Test PyPI 试跑：

```bash
UV_PUBLISH_TOKEN=<test-token> ./run-publish.sh --publish-url https://test.pypi.org/legacy/
```
