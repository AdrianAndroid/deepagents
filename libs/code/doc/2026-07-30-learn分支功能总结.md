## 二、模型配置与供应商支持优化

### 2.1 自定义供应商支持增强

**文件**: `libs/code/deepagents_code/model_config.py`

**改动要点**:

1. **默认模型字段**: `ProviderConfig` 新增 `default_model` 字段
   - 用户可在 `config.toml` 中为自定义供应商设置默认选中模型

2. **空供应商回退**: 当自定义供应商无配置模型时，自动添加 `"custom_model"` 占位
   - 保证首次安装用户能看到自定义供应商
   - 解决"模型设置失败"问题

3. **缓存逻辑简化**:
   - 移除 `_ollama_unreachable_endpoints` 负缓存
   - 简化 `_ollama_host_reachable` 超时处理逻辑
   - 移除复杂的网关配置检测 (`LANGSMITH_GATEWAY_PROVIDERS`)

4. **配置写锁移除**: 暂时移除 `_config_write_lock` RLock (需要评估影响)

### 2.2 OpenAI 兼容模型精确检测

**文件**: `libs/code/deepagents_code/configurable_model.py`

**改动要点**:

1. **OpenAI 端点精确匹配**:
   - 原逻辑：provider == "openai" 即启用 `prompt_cache_key`
   - 新逻辑：必须是 `api.openai.com` 或其官方子域名
   - 避免第三方 OpenAI 兼容端点因未知字段报错

2. **移除配置开关**:
   - 删除 `models.openai_prompt_cache_key` 全局开关
   - 改为自动检测端点兼容性

3. **CLI 上下文简化**:
   - 移除 `profile_overrides`、`model_context_limit`、`approval_mode` 字段
   - 保留 `auto_approve`、`approval_mode_key`、`thread_id`

## 五、发布与构建工具链（关键）

### 5.1 版本管理脚本

**新增文件**: `libs/code/bump-version.py`

**功能**:
- 原子更新三处版本位置：
  1. `pyproject.toml` → `[project].version`
  2. `deepagents_code/_version.py` → `__version__`
  3. `.release-please-manifest.json` → `"libs/code"` entry
- 支持 `--dry-run`、`--show` 选项
- 严格 semver 校验

### 5.2 本地发布脚本

**新增文件**: `libs/code/run-publish.sh`

**功能**:
- 使用 `uv build` 构建 wheel
- 使用 `uv publish` 上传到 PyPI
- 支持 Test PyPI 测试发布
- 凭证来源：`UV_PUBLISH_TOKEN` 或 `~/.pypirc`

### 5.3 GitHub Actions 发布流程

**新增文件**: `.github/workflows/publish-zjcode.yml`

**关键设计**:

1. **Trusted Publisher (OIDC)**:
   - 无需 PyPI token，通过 GitHub OIDC 认证
   - PyPI 侧已配置：Owner `AdrianAndroid`, Repo `deepagents`

2. **CI 内动态修改依赖版本**:
   ```yaml
   - name: Relax deepagents pin for published wheel
     working-directory: libs/code
     run: |
       sed -i -E 's|"deepagents==0\.7\.0a[0-9]+"|"deepagents>=0.7.0a7,<0.8.0"|' pyproject.toml
   ```
   - **目的**：用户 `uv tool install zjcode` 无需 `--prerelease=allow`
   - **优势**：保持 `pyproject.toml` 与上游完全一致，合并无冲突

3. **触发条件**:
   - Tag 推送：`zjcode-vX.Y.Z`
   - 支持 `workflow_dispatch` 手动触发（含 dry-run 选项）

### 5.4 发布 Skill

**新增目录**: `.deepagents/skills/publish-zjcode-version/`

**功能**:
- 标准化发布流程
- 前置检查（工作树清洁、分支、标签未使用、PyPI 未发布）
- 自动 patch 发布工作流（首次运行）
- 版本 bump → lockfile 刷新 → 提交 → tag → push

## 八、需要注意的潜在风险

### 8.1 配置写锁移除

- **位置**: `model_config.py` 移除了 `_config_write_lock`
- **风险**: 并发写入 `config.toml` 可能导致竞态条件
- **建议**: 评估是否需要重新引入更细粒度的锁

### 8.2 auto_mode.py 大幅删减

- **影响范围**: 自动模式、工具审批流、中断处理
- **建议**: 检查是否有功能缺失，特别是与用户审批相关的逻辑

### 8.3 LangSmith Gateway 功能移除

- **影响**: 使用 LangSmith Gateway 路由请求的用户可能无法正常工作
- **建议**: 如果需要支持网关，考虑恢复相关逻辑或提供替代方案
