# 2026-07-17 dcode-dev 本地部署测试

## 轮次 1 - 本地部署测试 dcode-dev

### 用户提问
本地部署测试 `dcode-dev`。

### 结论/方案
使用 `libs/code/run-dcode-dev.sh` 一键完成 editable 安装。脚本要点：

- 依赖 `uv`（不存在则报错退出）。
- 在 `${DCODE_DEV_VENV:-$HOME/.local/share/dcode-dev}` 创建独立虚拟环境（默认路径 `~/.local/share/dcode-dev`）。
- 用 `uv pip install --python <venv>/bin/python -e <libs/code> --upgrade` 把本仓库 `libs/code` 装成 editable，源码改动重启即生效。
- 在 `~/.local/bin/dcode-dev` 建软链指向 venv 内的 `dcode`（`console_scripts` 入口）。
- 若 `~/.zshrc` 未包含 `export PATH="$HOME/.local/bin:$PATH"` 则自动追加一行。

与其他运行方式的区别：
- `run-dcode-dev.sh`：装到 `~/.local/share/dcode-dev`，暴露全局命令 `dcode-dev`，与已发布的 `dcode` 并存。
- `uv run deepagents-code`（DEVELOPMENT.md 快速路径）：走 `libs/code/.venv`，仅在该目录下可用。
- `run-setup-dev-env.sh`：conda 环境（默认 `deepagents` / Python 3.12），同时装 build/twine/hatchling 等发布工具，适合发包场景。
