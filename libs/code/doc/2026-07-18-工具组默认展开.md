# 工具组默认展开（Tool Group Summary — expanded by default）

## 用户诉求

在 `deepagents-code`（dcode）TUI 中，多次连续的 `read_file` / `grep` / `glob`
会被聚合成一个 `ToolGroupSummary`（例如 `▼ Read 5 files`）。之前的默认行为是
**整个组折叠**——用户看不到具体调用了哪些文件、什么 pattern，需要点击展开。

诉求：**默认展开组，让每一次工具调用的橙色调用行都可见**；同时保持单个工具
结果 body 的默认收起（避免大段 read_file 输出淹没会话）。

## 方案权衡

| 方案 | 做法 | 影响 |
| --- | --- | --- |
| A | 把 `read_file / grep / glob` 加入 `_TOOL_GROUP_EXCLUSIONS`（`app.py:166`），彻底不聚合 | 破坏 **16 个测试**，且失去"折叠一整批"的可选择性 |
| **B（采纳）** | 把 `ToolGroupSummary._collapsed` 默认值从 `var(True)` 改为 `var(False)` | 组仍然形成（`▼ Read N files` 汇总头保留），但默认展开；只需要翻转 **6+ 处断言** |

方案 B 的优点：
- 保留了聚合结构和头部汇总（信息密度好）。
- 用户仍可点击头部"折叠一整批"。
- 单个工具 body 的收起逻辑（`_COLLAPSE_OUTPUT_BY_DEFAULT`）不受影响。
- 上游合并冲突面最小：只碰一行核心代码 + 测试断言。

## 轮次 1 - `read_file` / `grep` / `glob` 结果默认折叠（只显示橙色调用行）

### 用户诉求

进一步节省 TUI 屏幕空间：只想看到工具调用行本身（`read_file(ARCHITECTURE.md)`
这类橙色调用签名），**不要**自动展开显示文件内容 / 匹配行。之前工具执行成
功后会强制把 `read_file` / `grep` / `glob` 展开，body 直接铺在下面，很吃屏幕。

### 根因定位

`deepagents_code/tui/widgets/messages.py` `set_result()` 中（约 1569-1581 行），
成功回调里有一段"反向操作"：

```python
if (
    self._tool_name in _COLLAPSE_OUTPUT_BY_DEFAULT   # {"read_file","grep","glob"}
    or self._tool_name == "edit_file"
) and not self._is_search_no_result_output(self._output):
    self._expanded = True
```

即：虽然这些工具在 `_COLLAPSE_OUTPUT_BY_DEFAULT` 里被登记为"默认折叠"，但成
功后立刻被强制 `_expanded = True` 覆盖，body 一定会展开。作者原本的意图是
"看每一步实际读到 / 匹配到什么"，但用户偏好紧凑视图。

注意与上一会话（`ToolGroupSummary._collapsed`）的区别：
- 上一会话解决的是"多个工具聚合成一组，组是否默认折叠"；
- 本轮解决的是"单个工具的结果 body 是否默认展开"。
两处独立，互不影响。

### 修改

把 `read_file` / `grep` / `glob` 从强制展开条件里移除，只保留 `edit_file`
（不展开就看不到 diff）：

```python
# Only successful `edit_file` is force-expanded so the applied diff is
# visible. `read_file` / `grep` / `glob` (in `_COLLAPSE_OUTPUT_BY_DEFAULT`)
# stay collapsed by default — the header already carries the file path
# or pattern, and hiding the body keeps the log compact. Users can
# Ctrl+O to expand.
if self._tool_name == "edit_file" and not self._is_search_no_result_output(
    self._output
):
    self._expanded = True
```

### 效果

- `read_file(xxx.md)` / `grep(...)` / `glob(...)`：成功后只显示橙色调用行 +
  "N more — click or Ctrl+O to expand" 提示，body 收起。
- `edit_file(...)`：保持原样，成功后展开显示 diff。
- 错误路径（`set_error`）不受影响，仍然强制 `_expanded = True`——避免错误
  信息被藏起来。
- 需要看内容时 Ctrl+O / 点击即可展开。

### 关键路径

- `set_result()`：`deepagents_code/tui/widgets/messages.py:1548`
- `_COLLAPSE_OUTPUT_BY_DEFAULT`（**未改动**）：`messages.py:153`
- `set_error()`（**未改动**）：`messages.py:1627`
