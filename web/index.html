本页说明如何从内网私有 PyPI 仓库安装 deepagents-code(命令 dcode)。推荐使用 uv tool 隔离安装,不污染系统 Python。

1一键安装

请根据你的操作系统选择:

在终端(bash / zsh)中执行:

curl -fsSL http://8.152.204.58:40080/install.sh | bash
下载 install.sh 查看源码
脚本会自动检测并安装 uv,然后通过 uv tool install 从私有仓库拉取 deepagents-code。要求 Python 3.11+(uv 会自动下载合适的 Python)。

在终端(zsh / bash)中执行:

curl -fsSL http://8.152.204.58:40080/install.sh | bash
下载 install.sh 查看源码
与 Linux 使用同一份脚本。若尚未装 uv,脚本会通过 astral.sh 官方 installer 自动安装到 ~/.local/bin。

以 普通 PowerShell(不需要管理员)执行:

irm http://8.152.204.58:40080/install.ps1 | iex
下载 install.ps1 查看源码

若下载后本地执行,遇到执行策略限制可用:

powershell -ExecutionPolicy Bypass -File install.ps1
如果装了 WSL,也可以直接在 WSL 里跑上面 Linux 的方式,与原生 Windows 环境互不影响。

2手动安装(所有平台)

若你已经装好 uv,可跳过脚本直接执行:

uv tool install deepagents-code \ --index-url http://admin:admin@8.152.204.58:48080/simple/ \ --extra-index-url https://pypi.org/simple/ \ --index-strategy unsafe-best-match \ --force

Windows PowerShell 请用反引号续行,或直接写成单行:

uv tool install deepagents-code --index-url http://admin:admin@8.152.204.58:48080/simple/ --extra-index-url https://pypi.org/simple/ --index-strategy unsafe-best-match --force

安装完成后,任何目录下运行:

dcode

5版本检查镜像(JSON API)

dcode 内置的版本检查会请求 Warehouse JSON API。私有 pypiserver(48080) 只提供 Simple Index,没有该接口,因此本站(40080)额外托管了兼容的静态 JSON:

用途地址
主程序版本检查http://8.152.204.58:40080/pypi/deepagents-code/json
SDK 发布时间http://8.152.204.58:40080/pypi/deepagents/json

这两个 JSON 由 libs/code/run-build-upload.sh 在发布时自动生成(读取私有源当前版本列表)并部署到本站,免认证访问。删除旧版本后重新运行该脚本即可同步。

客户端默认已指向以上地址。如需切回公网 PyPI,可设置环境变量:
DEEPAGENTS_CODE_PYPI_URL=https://pypi.org/pypi/deepagents-code/json
可编辑(--editable)安装下自动更新始终禁用,版本检查仅用于"有新版可用"提示,不会自动下载重启。

6常见问题

找不到 dcode 命令

Linux / macOS —— 把 uv 的 bin 目录加入 PATH:

echo 'export PATH="$(uv tool dir --bin):$PATH"' >> ~/.zshrc && source ~/.zshrc

Windows —— 永久加入用户 PATH:

[Environment]::SetEnvironmentVariable('Path', "$(uv tool dir --bin);" + [Environment]::GetEnvironmentVariable('Path','User'), 'User')

验证安装

uv tool list dcode --version

升级到最新版本

uv tool upgrade deepagents-code
私有仓库当前使用 HTTP + 明文 Basic 认证(admin/admin),仅供内网使用,请勿在公网环境暴露。
