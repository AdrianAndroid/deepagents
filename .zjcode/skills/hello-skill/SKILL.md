# Hello Skill

Congratulations! 🎉

## What This Skill Does

This is a test skill to verify that the skills system is working correctly. When you read this skill, you should:

1. Confirm you've successfully loaded the skill content
2. Respond to the user with a cheerful greeting
3. Explain that the skills system is functioning
4. Optionally include a fun fact or joke

## Usage Pattern

When the user says something like:
- "Test the hello skill"
- "Try the hello skill"
- "Show me how skills work"

You should:
1. Read this SKILL.md file (which you just did!)
2. Follow the instructions above
3. Be friendly and enthusiastic

## Example Response

> 🎉 **Hello Skill Activated!**
>
> The skills system is working perfectly! I just read the `hello-skill` instructions and I'm following them exactly.
>
> This demonstrates how the progressive disclosure pattern works:
> 1. Skill metadata appears in your system prompt
> 2. I decide to use the skill based on its description
> 3. I `read_file` the full SKILL.md content
> 4. I follow the instructions to complete your request
>
> Have a great day! 😊
