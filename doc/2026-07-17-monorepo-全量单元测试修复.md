## 关键根因与修复

### libs/acp — 12 失败 (LangSmith run_tree 副作用)
- **原因**:环境 `LANGSMITH_TRACING=true` 时,`run_tree.patch()` 调 `pydantic.model_dump()` 会耗尽 `GenericFakeChatModel.messages` 迭代器,导致下次 `_generate` 抛 `StopIteration` → `RuntimeError`。
- **修复**:
  - 新增 `libs/acp/tests/conftest.py`,autouse fixture `_clear_langsmith_env` 屏蔽 `LANGSMITH_*` / `LANGCHAIN_*`。
  - `libs/acp/tests/chat_model.py` 的类 docstring 改成 `r"""..."""`,消除 `SyntaxWarning: invalid escape sequence '\s'`。

### libs/code — A 类 (用户 config.toml 泄漏)
- 用户主目录 `~/.deepagents/config.toml` 里配置了自定义 `huoshan` provider 和 `test-provider`,导致 8 个测试受污染。
- 修复:
  - `test_model_config.py::TestSplitCredentialSource._isolate_openai_env` 增加 `tmp_path` 参数,monkeypatch `DEFAULT_CONFIG_PATH`,并调用 `_mc.clear_caches()` 隔离。
  - `test_no_warning_when_config_base_url_literal_set` 断言限定为"API key resolved from" 拆分警告,过滤 `ModelConfig.load()` 的 DEBUG 日志。
  - `test_auth_widgets.py::test_only_installed_well_known_providers_listed` 在测试隔离修复后已通过。

### libs/code — B 类 (漂移测试:代码真实缺项)
- `/add-provider` 出现在 `app.py` help_body 却未在 `COMMANDS` 注册:
  - `command_registry.py` 中 `/model` 后追加 `SlashCommand(name="/add-provider", bypass_tier=QUEUED, argument_hint=...)`。
  - 运行 `make commands-catalog` 重新生成 `COMMANDS.md`。
- `DEEPAGENTS_CODE_NO_MOUSE` 没有 `ConfigOption`:
  - `config_manifest.py` 追加 `display.no_mouse` 布尔选项,绑定 `_env_vars.NO_MOUSE`。

### libs/code — C 类 (mouse kwarg 兼容)
- `_fake_run_async(self)` 不接受 `run_textual_app` 传入的 `mouse=` 参数。
- 修复:`test_main.py::_fake_run_async` 签名改为 `(self, **_)`。

### libs/code — D 类 (UI 真实回归)
1. **`/scrollbar`、`/timestamps`、`/editor` 命令回显破坏 toast-only 设计**
   - 用户提交 `4a7d4c1c` 把 `UserMessage(command)` 集中到 `_handle_command` 顶部,使原本没有回显的三个命令也开始 mount UserMessage,导致 `/scrollbar` `/timestamps` 断言额外 UserMessage,且 `/editor` 在 `_chat_input` 被 Mock 时触发 `ScreenStackError`。
   - 修复:在 `_handle_command` 顶部保留集中回显,但增加 `_no_echo_cmds = {"/scrollbar", "/timestamps", "/editor"}` 白名单跳过,恢复 toast-only 语义。
2. **`ModelSelectorScreen.on_input_changed` 丢失 `call_after_refresh(self._update_display)`**
   - 提交 `4a7d4c1c` 新增 `on_button_pressed` 时,把原来 `on_input_changed` 末尾的 refresh 调用错误地"移动"进了新方法。造成过滤后 `_update_display` 不再触发,`Recent` 分组和 footer 不刷新。
   - 修复:在 `on_input_changed` 末尾重新加上 `self.call_after_refresh(self._update_display)`,让 5 个 model_selector 测试同时恢复正常。
3. **`CustomProviderModalScreen.action_submit` 未清残留 error**
   - 用户新写的 `test_default_model_input_validation` 一路 submit 到 valid 之后期望 error_widget 内容为空,但实际残留上一次的 255-char 消息。
   - 修复:`action_submit` 一进入就 `error_widget.update("")`。
4. **`test_default_model_input_validation` 断言方式错误**
   - 用了 `str(error_widget)` 和 `.renderable.plain`,应统一用 `str(error_widget.content)`。
5. **`test_keyboard_accessibility` 断言 Tab 顺序错误**
   - Compose 里 save-btn 在 cancel-btn 之前,测试写反了。交换断言顺序。
6. **`test_existing_functionality_regression` 误用 `await modal.action_cancel()`**
   - `action_cancel` 是同步方法,去掉 `await`。
7. **`test_server.py::test_start_cleans_up_partial_state_on_health_failure`**
   - 全局 `DEEPAGENTS_CODE_DEBUG=1` 会让 `ServerProcess.stop()` 保留 log 文件。用 `monkeypatch.delenv("DEEPAGENTS_CODE_DEBUG", raising=False)` 隔离。
