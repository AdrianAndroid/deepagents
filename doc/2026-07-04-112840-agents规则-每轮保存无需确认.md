# AGENTS 规则强化:每轮问答保存无需确认

- Time: 2026-07-04T11:28:40+08:00
- Project: deepagents

## 用户提问要点
上一轮回答末尾问了「需要我把这次问答按新规则追加到 doc/ 吗?」。
用户回复:**"每次都需要"** —— 明确要求以后每轮都保存,不要每次询问。

## 结论与操作
1. **补齐今天已遗漏的三轮问答**,已写入:
   - `doc/2026-07-04-111500-editorconfig插件说明.md`
   - `doc/2026-07-04-112000-libs多包结构说明.md`
   - `doc/2026-07-04-112500-私有pypiserver上传与安装命令.md`
2. **强化 AGENTS.md 规则**,把「每轮保存」定为**默认自动行为**,禁止询问:
   - `AGENTS.md` 「## 文档留存规则」第 1 条,追加加粗强调:
     > 必须**主动、自动**立即...**禁止在保存前询问用户是否需要保存**——这是默认行为,无需确认;即使用户没有明确要求也必须保存。

## 关键学习点
- 用户反馈明确后,不仅要执行当次任务,还要**修改规则本身**,让后续行为不再依赖询问确认。
- 遇到「每次都要 X」这种表达,等同于「把 X 设为默认行为并禁止确认」。
