# Explain TUI

- Time: 2026-07-01T13:57:34+08:00
- Project: deepagents

## Prompt

TUI是什么?

## AI Response

TUI 是 **Terminal User Interface**，意思是“终端用户界面”。

它不是普通命令行一次输入一次输出，也不是浏览器/桌面 GUI，而是在终端里显示类似应用界面的交互程序。

例如 `uv run dcode` 启动后，会在终端里出现聊天窗口、状态栏、输入框、快捷键、slash commands，这就是 TUI。

简单对比：

- CLI：`dcode -x "修复 bug"`，执行一次就结束
- TUI：`dcode`，进入终端里的交互式聊天应用
- GUI：浏览器或桌面窗口应用
