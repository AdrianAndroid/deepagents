# 私有 pypiserver 上传与安装命令

- Time: 2026-07-04T11:25:00+08:00
- Project: deepagents

## 用户提问要点
如何把包上传到私有 pypiserver,上传命令和安装命令分别是什么。

## 上传前置:构建包
```bash
cd libs/code       # 或其他要发布的包目录
uv build           # 在 dist/ 下生成 .whl 和 .tar.gz
```

## 上传方式 A:twine(推荐,标准做法)
pypiserver 兼容 PyPI 上传协议。

配置 `~/.pypirc`(免每次输入密码):
```ini
[distutils]
index-servers = local

[local]
repository = https://pypi.example.com/
username = 用户名
password = 密码
```

上传:
```bash
uv run --with twine twine upload -r local dist/*

# 或直接指定 URL
uv run --with twine twine upload \
  --repository-url https://pypi.example.com/ \
  -u 用户名 -p 密码 \
  dist/*
```
注意上传用根路径 `/`,不是 `/simple/`。

## 上传方式 B:scp 直传
pypiserver 只是扫描 packages 目录,可直接推 wheel:
```bash
scp libs/code/dist/deepagents_code-0.1.25* root@服务器IP:/opt/pypiserver/packages/
```
pypiserver 会自动发现,无需重启。

## 两种方式对比
| | twine | scp |
|---|---|---|
| 协议 | HTTPS + 认证 | SSH |
| 需要开放上传端点 | 需要(启动参数含 `update`) | 不需要 |
| 幂等性 | 自动拒绝重复版本 | 会覆盖 |
| 适合 | 团队/CI/CD | 单人手动 |

## 安装命令

### pip
```bash
pip install --index-url https://用户名:密码@pypi.example.com/simple/ deepagents-code

# 自签证书或内网域名
pip install --index-url https://用户名:密码@pypi.example.com/simple/ deepagents-code \
  --trusted-host pypi.example.com
```

### uv(推荐)
```bash
uv tool install -U --index-url https://用户名:密码@pypi.example.com/simple/ deepagents-code
uv tool install -U --python 3.13 --index-url https://用户名:密码@pypi.example.com/simple/ deepagents-code
```

### 项目 pyproject.toml 配置私有源
```toml
[[tool.uv.index]]
name = "private"
url = "https://用户名:密码@pypi.example.com/simple/"
default = false
```
```bash
uv add --index private deepagents-code
```

## 升级
```bash
uv tool install -U --index-url https://用户名:密码@pypi.example.com/simple/ deepagents-code
pip install -U --index-url https://用户名:密码@pypi.example.com/simple/ deepagents-code
```

## 自检
浏览器访问 `https://pypi.example.com/simple/deepagents-code/`,能看到版本列表即正常。

## 注意事项
1. 反代根路径映射到容器 `8080`;安装用 `/simple/`,上传用 `/`
2. pypiserver 启动参数必须含 `-a update,download,list` 才允许上传
3. pypiserver 默认拒绝已存在的相同版本号,发新版必须改 `pyproject.toml` 的 `version`
4. URL 中密码明文暴露,推荐用 `.pypirc`、`.netrc` 或环境变量,不写死在命令里
