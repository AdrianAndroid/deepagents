# AGENTS 规则更新 - 单轮问答结束状态与耗时标记

## 会话背景
用户希望在每轮问答记录末尾追加"结束状态 + 本轮总耗时"，作为该轮记录的收尾标识，既能识别问答确已完结，又能区分正常结束与异常/中断结束，便于后续复盘、统计与审计。

## 用户诉求要点
- 每一轮问答记录末尾需要有明显的"结束标记"。
- 标记内容需要包含：结束结果（正常 / 异常）+ 本轮总时间。
- 目的：判断"是否结束"与"以何种方式结束"。

## 结论 / 方案
在 `AGENTS.md` 的"文档留存规则"章节新增第 7 条规则：**单轮结束标记**。

规则要点：
1. 每轮问答记录末尾必须追加一行结束状态标记，使用 Markdown 引用块（`> `）以在视觉上与正文区分。
2. 统一格式：
   ```
   > ⏹ 结束状态：<状态> | ⏱ 总耗时：<HH:MM:SS 或 Xs> | 🕒 结束时间：<YYYY-MM-DD HH:MM:SS>
   ```
3. `<状态>` 取值语义：
   - `✅ 正常结束`：任务完整完成。
   - `⚠️ 异常结束`：工具报错、需求未达成、被中途打断等。
   - `⏸ 用户中断`：用户主动 stop / Ctrl+C。
   - `🚫 拒绝执行`：用户拒绝工具调用或本轮无实际操作。
4. `<总耗时>` = 本轮 user 消息发出到 assistant 最终回复完成的墙钟时间；无法精确获取时使用估算值并加 `(估算)` 后缀。
5. 位置：必须位于本轮所有小节内容之后、下一轮标题或会话分隔符之前，作为单轮记录的最后一行。
6. 异常 / 中断情况需再另起一行（同样 `> ` 引用块）简述原因或中断上下文，便于复盘。

## 关键文件改动
- `AGENTS.md`：在"文档留存规则"章节末尾追加第 7 条"单轮结束标记"规则条目及格式说明。
