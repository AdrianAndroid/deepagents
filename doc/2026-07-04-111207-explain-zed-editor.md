# Zed 编辑器是什么

### 轮次 1 - Zed 编辑器介绍

**用户提问要点**
- 询问 Zed 编辑器是什么。

**结论/方案**
Zed 是一款现代高性能代码编辑器，核心特点：

- **Rust 编写**：追求极致速度和低延迟，采用 GPU 加速渲染。
- **实时协作**：内置多人协同编辑功能，类似 Google Docs 的编程版。
- **AI 集成**：内置 AI 助手，并支持 ACP（Agent Client Protocol）。
- **开源**：由 Atom 和 Electron 的原班团队打造。

**与本仓库的关联**
- `libs/acp`（`deepagents-acp`）是 Agent Client Protocol 适配层，用于把 Python Deep Agent 暴露给像 Zed 这类支持 ACP 的编辑器使用。
