# AGENTS 规则更新:每轮问答实时留存

## 背景
用户询问「每次问答都保存本地」这条规则是否存在于 `/Users/zhaojian/code/deepagents/AGENTS.md`。原规则只要求「每次会话结束后」做结构化总结,颗粒度是整会话级,并非每轮问答级。

## 用户诉求
将规则细化为**每一轮问答(单次 user → assistant 交互)结束后立即追加保存**,而不是等整个会话结束再一次性总结。

## 变更内容
文件:`/Users/zhaojian/code/deepagents/AGENTS.md` 的「## 文档留存规则」章节(约 600–612 行)整段替换。

### 关键改动
1. 第 1 条从「每次会话结束后总结」改为「**每一轮问答结束后立即追加保存**,不得等整个会话结束再一次性总结」。
2. 新增第 4 条「单轮追加格式」:每轮追加时用二级/三级标题(如 `### 轮次 N - 主题`)分块,记录用户提问要点、结论/方案、关键操作或文件改动、后续 TODO。
3. 第 3 条命名规范补充:**同一天同一主题的多轮问答追加到同一文件**。
4. 第 6 条(原第 5 条)会话分隔符规则补充说明:**同一会话内的多轮问答不使用 NEW SESSION 分隔符**,仅通过标题层级区分;分隔符只用于跨会话边界。

## 最终规则要点
- 每轮问答结束立即追加到 `doc/YYYY-MM-DD-主题-摘要.md`
- 同一天同一主题追加到同一文件,轮次间用标题分隔
- 跨会话之间才使用 `--- ✨...【 NEW SESSION 】✨... ---` 分隔符
- 内容需可复用、准确完整,包含需求/方案/操作/TODO
