# EditorConfig VS Code 插件说明

## 用户提问要点
用户贴了 VS Code 插件市场里 `EditorConfig for VS Code` 的截图,问这是什么插件、做什么用的。

## 结论
`EditorConfig for VS Code` 是让 VS Code 读取项目根目录 `.editorconfig` 文件的插件,用于**跨编辑器统一代码风格**(缩进、换行符、编码、行尾空格、末尾换行等)。

## 关键点
- **作用**:多人协作/多编辑器场景下,VS Code / IntelliJ / Vim / Sublime 都遵循同一份 `.editorconfig`,避免风格漂移和无意义 diff。
- **优先级**:`.editorconfig` 覆盖 VS Code 的 `settings.json`(如 `editor.tabSize`)。
- **常见配置项**:
  - `indent_style` = space / tab
  - `indent_size` = 数字
  - `end_of_line` = lf / crlf
  - `charset` = utf-8
  - `trim_trailing_whitespace` = true/false
  - `insert_final_newline` = true/false
  - `[Makefile]` 段落里 `indent_style = tab`(Makefile 必须 tab)
  - `[*.md]` 段落里 `trim_trailing_whitespace = false`(Markdown 行尾双空格是换行)
- **是否需要装**:
  - 多人协作/跨编辑器项目:推荐装
  - 纯个人 + 只用 VS Code:可装可不装
