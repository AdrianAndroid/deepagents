# dcode二次开发版本分发与1Panel部署指南
---
## 一、可行性说明
1Panel面板完全适合作为Deep Agents二开版本的分发平台，根据不同的分发场景可以选择对应的部署方案，操作简单，可视化管理，安全可控。
---
## 二、不同分发场景对应的1Panel实现方案
### 方案1：私有PyPI源分发（适合企业/团队内部分发Python包）
**适用场景**：团队内部成员直接通过`pip install`安装你的定制版dcode，最符合Python开发者使用习惯
**1Panel部署步骤**：
1. 打开1Panel应用商店，搜索安装`pypiserver`（私有PyPI源服务）
2. 配置访问权限（绑定内网域名、设置账号密码鉴权）
3. 把你打包好的`deepagents-code-xxx.whl`包上传到pypiserver的包目录
4. 团队成员使用时只需要配置源：
   ```bash
   pip install --index-url http://你的内网pypi地址/simple/ deepagents-code --trusted-host 你的域名
   ```
---
### 方案2：静态文件下载站（通用场景，适合所有分发需求）
**适用场景**：分发二进制包、安装脚本、Docker镜像说明文档等，最简单易用
**1Panel部署步骤**：
1. 新建静态网站，绑定域名，配置HTTPS证书（1Panel一键申请）
2. 把你打包好的内容上传到网站根目录：
   - 跨平台二进制包（Windows/macOS/Linux版本）
   - 一键安装脚本（比如`install.sh`/`install.ps1`）
   - 使用文档、更新日志
3. 用户直接访问你的下载站，下载对应版本安装即可，还可以提供一键安装命令：
   ```bash
   curl -fsSL https://你的下载域名/install.sh | bash
   ```
---
### 方案3：私有Docker镜像仓库（适合容器化部署场景）
**适用场景**：你的定制版本打包成Docker镜像分发，用户直接拉取镜像运行
**1Panel部署步骤**：
1. 应用商店安装`Harbor`（企业级Docker镜像仓库）或者直接用1Panel自带的容器镜像管理功能
2. 把你构建好的`dcode:custom-vx.x.x`镜像推送到私有仓库
3. 用户直接拉取运行：
   ```bash
   docker run -it --rm 你的镜像地址/dcode:latest
   ```
---
### 方案4：SaaS化在线服务端部署（适合对外提供产品服务）
**适用场景**：你想做成类似Claude Code的在线服务，用户不用本地安装，直接通过客户端/浏览器连接使用
**1Panel部署步骤**：
1. 部署dcode的服务端到1Panel的Python运行环境/容器中
2. 配置域名、端口映射、HTTPS、负载均衡
3. 可以配合1Panel的MySQL/Redis数据库实现用户管理、会话存储、权限控制等功能
4. 用户只需要安装轻量客户端，连接你的服务端即可使用，不需要本地部署Python环境和大模型
---
## 三、用1Panel做分发平台的优势
1. **可视化管理**：所有服务一键部署，不用手写配置文件，域名、证书、备份都可以在面板里操作
2. **安全可控**：自带防火墙、访问控制、防暴力破解，内部分发可以配置只允许公司IP访问
3. **自带监控**：可以看下载量、访问量、服务运行状态，异常自动告警
4. **成本极低**：只需要一台普通1核2G的服务器就能支持几百人规模的分发需求
5. **升级方便**：新版本发布只需要上传新的包到对应位置，用户端一键更新即可
---
## 四、注意事项
1. 如果是内部分发，建议不要公开到公网，配置IP白名单或者账号密码鉴权
2. 所有下载链接一定要配置HTTPS，避免安装包被篡改
3. 大版本更新建议保留旧版本下载地址，给用户升级缓冲时间
4. 如果分发规模大，可以配合1Panel的CDN加速功能，提升下载速度
