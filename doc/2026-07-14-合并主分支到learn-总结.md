## 学到的经验（Update to memory guidelines）

- 合并前先 `git branch <backup>` 是硬性纪律，本次也执行了。
- 遇到 `refs/remotes/origin/main` 无法更新（"is at X but expected Y"），用 `git update-ref -d refs/remotes/origin/main` 重置该本地远端引用即可重新 fetch。
- 冲突里出现"文件重命名"（例如 `libs/code/deepagents_code/widgets/...` → `libs/code/deepagents_code/tui/widgets/...`）时，Git 会在冲突块头部标注两侧原始路径（`<<<<<<< HEAD:old/path` / `>>>>>>> main:new/path`），提示重构类冲突需要"内容合并到新路径"。
- 私有分支保留私有版本号策略：`_version.py` / `pyproject.toml` / `.release-please-manifest.json` / `uv.lock` 四个文件是"版本号真理源"，必须一起校准。
