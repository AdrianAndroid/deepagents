# 2026-07-19 发布 zjcode 0.0.5

## 用户请求
"发布版本0.0.5"

本次发布包含首次启动时也能添加自定义厂商的改动（在 curated/onboarding 模型选择界面显示 "Add Custom Provider (Ctrl+A)" 按钮）。

## 执行步骤
1. 预检
   - `git status`：干净（本地领先 origin/learn 1 个 commit：`首次也能自定义`）
   - 分支：`learn` ✅
   - `git tag -l "zjcode-v0.0.5"`：不存在 ✅
   - PyPI 0.0.5：404 ✅
2. `python libs/code/bump-version.py 0.0.5` → 三处同步（pyproject / _version.py / release-please-manifest）
3. `uv lock` → Updated zjcode v0.0.4 → v0.0.5
4. `uv build` 本地构建通过（生成 wheel + sdist）
5. `git commit` + `git push origin learn`（把 bump 提交与上一轮的功能提交一起推上去）
6. `git tag zjcode-v0.0.5` + `git push origin zjcode-v0.0.5`
